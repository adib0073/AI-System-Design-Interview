# Chapter 7 — Agentic AI Systems

Companion resources for Chapter 7. Maintained here (not in the printed book) so they can be kept current — especially the fast-moving MCP/A2A/framework landscape.

Chapter 7 covers autonomous agents: architecture patterns (ReAct, Plan-and-Execute, Reflexion, ToT/GoT), tools & MCP, multi-agent orchestration (orchestrator/supervisor/swarm) & A2A, memory, planning, and safety/governance.

| File | What it is |
|------|------------|
| [`agent-pattern-selection.md`](./agent-pattern-selection.md) | Cheat sheet for choosing the reasoning pattern and single vs. multi-agent (orchestrator / supervisor / swarm), with quick-routing flows and a one-paragraph interview answer. |
| [`safety-governance-checklist.md`](./safety-governance-checklist.md) | Worksheet: sandboxing/permissions, action validation & confirmation gates, loop & cost limits, rate limiting, guardrails, HITL, failure handling, observability — plus a risk-tiering reference. |
| [`mcp-a2a-references.md`](./mcp-a2a-references.md) | **Living reference**: MCP & A2A specs, agent frameworks, sandboxing runtimes, and observability/eval tools. Focus on trade-offs, not spec details. |
| [`key-terms.md`](./key-terms.md) | Chapter 7 glossary slice (ReAct, Reflexion, ToT/GoT, MCP, A2A, episodic/semantic/procedural memory, guardrails, trajectory tracing, …). Feeds the cumulative book glossary. |
| [`common-doubts.md`](./common-doubts.md) | Answers to the questions candidates most often have — when to use agents, single vs multi-agent, MCP depth, memory choices, cost control, and how to structure the whole answer. |

> **Note on links:** the MCP/A2A/framework ecosystem changes fast — `mcp-a2a-references.md` is intentionally a living document. If a link is dead, search the project name or open an issue/PR.
