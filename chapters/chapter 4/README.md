# Chapter 4 — Core AI System Concepts

Companion resources for Chapter 4. Maintained here (not in the printed book) so they can be kept current.

Chapter 4 is the AI-lifecycle foundation: framing the problem, data engineering, features & feature stores, model selection (classical → deep → foundation/GenAI), evaluation (offline → online → business), serving, and MLOps/monitoring.

| File | What it is |
|------|------------|
| [`practice-bank.md`](./practice-bank.md) | Practice problems with answer keys for the three recurring questions: **"does this need ML?"**, **metric selection**, and **drift scenarios** (data vs concept vs prediction). |
| [`decision-trees-checklists.md`](./decision-trees-checklists.md) | Decision trees and checklists for **model selection** and **feature stores**, including explicit **GenAI (prompt/RAG/fine-tune)** and **agentic** branches. |
| [`engineering-blogs.md`](./engineering-blogs.md) | Blog/paper index: ML platforms (Uber Michelangelo), feature stores (Feast/Tecton/Chronon), evaluation/experimentation, serving, and MLOps/monitoring — with role-specific picks. |
| [`key-terms.md`](./key-terms.md) | Chapter 4 glossary slice (feature store, embedding, bi-/cross-encoder, RAG, canary/shadow, the three drifts, …). Feeds the cumulative book glossary. |
